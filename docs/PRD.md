# ETF 적립식 투자 최종 금액 예측 앱 PRD
## 1. Why - 목적
최근 3년 평균 수익률 기반 적립식 투자 최종 금액 예측
종목·기간·월 투자금·초기 자본 조건별 결과 사전 확인
투자 의사결정을 위한 수치 근거 제공
---
## 2. Who - 타깃 사용자
ETF 적립식 투자를 시작하려는 초보 투자자
현재 적립 중이며 최종 금액을 예측하려는 투자자
조건별 결과를 비교하려는 사용자
## 3. User flow
앱 진입
ETF 종목 선택
최근 3년 평균 수익률 선택
투자 기간 선택 (개월 단위)
월 투자 금액 선택
초기 투자 자본 입력
계산 실행
최종 예측 금액 확인
조건 수정 후 재계산
## 4. 기능 요구 사항
### P0. 핵심 기능
*ETF 종목 선택
*종목 검색 (종목명/티커)
*종목 1개 선택
*최근 3년 평균 수익률 선택
선택한 종목의 최근 3년 평균 수익률 표시
해당 수익률을 예측 계산에 적용
투자 기간 선택
개월 단위 선택/입력
유효성 검증 (1개월 이상)
월 투자 금액 선택
금액 선택/입력
0원 이하 입력 차단
초기 투자 자본 입력
숫자 입력
0원 허용
최종 금액 예측 계산
입력값: 초기 자본, 월 투자금, 개월 수, 평균 수익률
총 투자 원금 = 초기 자본 + (월 투자금 × 개월 수)
월 복리 적용 최종 예상 금액 산출

결과 화면

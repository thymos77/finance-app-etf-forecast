|---|---|---|---|
| A1 | 플랫폼 | 웹 SPA: Vite + React + TypeScript | 정적 배포가 가능하고, P1 링크 공유와 잘 맞음 |

| A5 | 납입 시점 | 매월 말 납입 (기말 연금) | 업계 계산기에서 흔한 기본값. 월초 납입은 P1 옵션 후보 |
| A6 | 통화·반올림 | 원(KRW), 계산은 부동소수점, 표시만 원 단위 반올림 | 표시 오차가 누적되지 않도록 |
| A7 | 입력 상한 | 기간 ≤ 600개월(50년), 금액 ≤ 1,000억 원 | 비정상 입력으로 Infinity나 레이아웃 깨짐이 생기는 것을 방지 |

## 3. 계산 명세 (P0 핵심)

```
입력: P0(초기 자본 ≥ 0), M(월 투자금 > 0), n(개월 ≥ 1, 정수), R(연 수익률, 소수, R > −1)
r        = (1 + R)^(1/12) − 1
원금     = P0 + M × n
최종금액 = P0 × (1 + r)^n + M × ((1 + r)^n − 1) / r      (r = 0 이면 P0 + M × n)
수익금   = 최종금액 − 원금
수익률%  = 수익금 / 원금 × 100
```

기준 테스트 값 (Python으로 계산해 검증함):

| P0 | M | n | R | 원금 | 최종금액 (원 반올림) |
|---|---|---|---|---|---|
| 1,000,000 | 100,000 | 12 | 12% | 2,200,000 | 2,384,650 |
| 0 | 100,000 | 36 | −10% | 3,600,000 | 3,100,115 |
| 0 | 100,000 | 36 | 0% | 3,600,000 | 3,600,000 |

- **완료 기준:** `npm run build`, `npm test`, `npm run lint` 가 모두 exit 0

### Phase 1 — 계산 엔진 (TDD)
- `src/domain/calculate.ts`: `calculateProjection({ initial, monthly, months, annualRate })` → `{ principal, finalAmount, profit, profitRate }`
- `src/domain/validate.ts`: 필드별 오류 코드 반환 (`MONTHS_MIN`, `MONTHLY_POSITIVE`, `INITIAL_NONNEGATIVE`, `NOT_A_NUMBER`, `OUT_OF_RANGE`)
- **완료 기준:**
  - §3 표의 3개 케이스가 원 단위 반올림으로 정확히 일치
  - r = 0 분기에서 0으로 나누지 않음 (NaN/Infinity 없음)
  - 검증: `months=0` → `MONTHS_MIN`, `monthly=0` 및 `−1` → `MONTHLY_POSITIVE`, `initial=0` → 통과, `initial=−1` → `INITIAL_NONNEGATIVE`, `months=1.5` → 오류
  - `domain/` 라인 커버리지 100%

### Phase 2 — ETF 데이터와 검색
- `src/data/etfs.json` 스키마: `{ ticker, name, threeYearCagr, asOf }[]`
- `etfRepository.ts`: `search(query)`는 종목명 부분 일치 + 티커 접두 일치, 대소문자·공백 무시, 최대 10건
- `EtfSearch.tsx`: 입력, 결과 목록, 키보드 선택(↑↓ Enter)으로 1개 선택. 선택 후 3년 평균 수익률과 기준일 표시
- **완료 기준:**
  - "kodex"와 "KODEX"의 검색 결과가 같음, 티커 접두 검색 동작, 결과 0건이면 "검색 결과 없음" 표시
  - 종목 선택 시 수익률이 `xx.xx%` 형식으로 표시되고 계산 입력값으로 들어감

### Phase 3 — 입력 폼
- `InputForm.tsx`: 기간(개월), 월 투자금, 초기 자본. 각 필드에 프리셋 칩(예: 12/36/60/120개월, 10/30/50/100만 원)과 직접 입력 제공
- 금액 입력 시 천 단위 콤마 표시, 내부 값은 숫자
- 오류는 필드 아래 인라인으로 표시하고, 오류가 있으면 "계산하기" 버튼 비활성화
- **완료 기준 (RTL 테스트):**
  - 월 투자금 0 입력 → 오류 문구 표시 + 버튼 disabled
  - 초기 자본 0 → 오류 없음
  - 종목 미선택 → 버튼 disabled

### Phase 4 — 결과 화면과 재계산
- `ResultCard.tsx`: 총 투자 원금, 최종 예상 금액, 예상 수익금, 수익률(%) 표시. 음수 수익은 색상과 부호로 구분
- 조건을 바꾸고 다시 계산하면 결과가 갱신되고, 입력값은 유지됨 (`PRD.md:20`)
- "과거 수익률 기반 추정이며 미래 수익을 보장하지 않습니다" 고지 문구 표시
- **완료 기준:**
  - §3 케이스 1 입력 → 화면에 "2,384,650원", 원금 "2,200,000원", 수익률 "8.39%"
  - 값 하나만 바꿔 재계산 → 결과만 바뀌고 나머지 입력은 유지
  - 375px 폭에서 가로 스크롤 없음
